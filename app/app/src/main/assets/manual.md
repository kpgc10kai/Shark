# Shark User Manual

Shark drives the on-device 98260 exploit as shell through Stellar or Shizuku to load the manager LKM. On first use, complete authorization first, then jailbreak with one tap.

> Shark currently supports OPPO/OnePlus devices running kernels 6.18.21, 6.12.69, 6.12.38, 6.12.58, 6.12.23 and 6.6.118, matched exactly against the full `uname -r`; unmatched models are reported as unsupported.

## Quick Start

1. Install the ROOT manager of your choice first (KernelSU / FinaSU / KernelSU Next / BakaSU / SukiSU Ultra); **KernelSU Next CI builds are not supported yet**.
2. Start and activate the **Stellar (recommended)** or **Shizuku** service through **wireless debugging or adb**, and grant Shark the permission.
3. Return to the Shark home page and tap "One-Tap Jailbreak", then wait for the success log; consider it successful when you see `DONE`, `SU_ID_RC=0` and `uid=0(root)`.
4. On success the manager is launched automatically; when the corresponding switches are enabled it also disables security pop-ups and loads **SUSFS** (6.18/6.12 branches; 6.12 uses `libsusfs_guard_lkm_612.so`) or **VFS** (6.18.21 only).
5. If the log shows **MODULE NOT LOADED**, there is no need to reboot the device — just try the jailbreak again.
6. Every time you enter the app it checks for updates automatically: Gitee Releases first, GitHub as fallback; when a new version is found a dialog appears, and you can download it directly and hand it to the system installer. You can also tap "Check for updates" manually on the "About" page.

## Permissions and Preparation

- **Stellar first, Shizuku as fallback**: when both are available Stellar is used; only when Stellar is unavailable does it fall back to Shizuku.
- **The manager must be installed first**: ksud is not bundled; at runtime it is executed in place from `lib/arm64` of the manager APK.
- **Running it after a clean boot is recommended**; 6.18.21, 6.12.69, 6.12.38, 6.12.58, 6.12.23 and 6.6.118 are separate entry points, and the app selects exactly by the full `uname -r`.

## One-Tap Jailbreak Flow

**preflight** (kernel release / trace channel) → **98260 UAF** (fake cred / SELinux zero write) → **one-shot ksud late-load from a cred child process** → wait for the module and su → **finalization** (ksud install, remove kernel protections, SUSFS, VFS, screenshot restore, launch the manager).

Each kernel version has its own K source file and `libk<version>.so`; there is no source-level reuse, and the shared engine lives in `plant_core.inc`. On vivo models (6.12.23 / 6.12.58 vivo builds), the `__tracepoint_sys_exit->funcs` slot used by `vr.ko` is zeroed before the root child process is woken.

- **Fast path**: plant takes about 2–3 seconds and the full flow about 4–9 seconds; when reclaim misses it takes a few seconds longer, which is normal fluctuation.
- **After any chain failure**: the pages held by plant are handed over to a holder, and you can tap again directly in the same boot; do not manually kill or reap the holder.

## Features

- **Home**: ROOT manager dropdown, flow switches (VFS is shown on 6.18 only; vivo V2505A hides the three anti-root items; 6.6.118 does not show SUSFS/VFS/hot switching); the info card shows the kernel version and the automatically selected exploit method.
- **Log**: live streaming log of the current run.
- **History**: one `.log` is saved per run; tap an entry to see the full text, swipe left on an entry to reveal the "Export" button and share it with other apps.
- **About**: version number, check for updates, source code / join the community / report an issue entries, as well as the dependency list generated by AboutLibraries (shows the version and license per library, tap to see details) and the full text of the open-source licenses bundled offline in the APK (GPL-3.0, NOTICE, Apache-2.0, MIT, GPL-2.0, MPL-2.0).
- **Extended features → Droidspaces support** (6.18.21 only): tapping "Download module" fetches the latest release of `Droidspaces-LKM` on GitHub, and after confirmation downloads the module zip; the file is saved to `Download/Shark/`, after which you go to the KernelSU manager under "Modules → Install" and select that file to flash. The module is not bundled in the APK.
- **ROOT manager → Dynamic Switching** (6.18.21 / 6.12.69 / 6.12.38 / 6.12.58 / 6.12.23; not supported on 6.6.118): once selected, run once on a clean boot and `libksud_universal.so` loads the universal KSU LKM (initially KernelSU, embedding both the 6.18/6.12 KMI KOs). After loading, the "Manager hot switching" item appears in extended features, where you can switch among KernelSU / KernelSU-Next / BakaSU / SukiSU / FinaSU without rebooting or re-jailbreaking; reopen the target manager app after switching.

## Troubleshooting

| Log | Action |
| --- | --- |
| `PROBE_FAIL` / `kernel mismatch` | The current kernel is not in the supported list (matching is by exact `uname -r` only, against the supported 6.18.21 / 6.12.69 / 6.12.38 / 6.12.58 / 6.12.23 / 6.6.118). |
| `MANAGER` / `KSUD_MISSING` | Install the corresponding manager APK before running. |
| `STALE_PLANT` | The previous plant is still running; wait for it to turn into a holder, then retry. |
| `PLANT_FAIL` | plant keeps the holder and exits; you can retry directly in the same boot. |
| `LATE_LOAD_FAIL` | The module did not appear within the time limit; check the ksud output in the log, confirm the manager version matches, then retry directly. |
| Kernel panic/reboot | An inherent risk of the 98260 race; reboot and run again. |

## Run Modes

- **6.18.21** → `libk61821.so`; **6.12.69** → `libk61269.so` (the two OTA builds select the call site by uname).
- **6.12.38 (PLR110)** → `libk61238.so`; **6.12.58 (PLZ110 / V2505A OS6/OS7)** → `libk61258.so`; **6.12.23 (V2505A)** → `libk61223.so`.
- **6.6.118 (PKJ110 / PKH110 / Pad, etc.)** → `libk66118.so` (the two OTA builds select the call site by uname); KMI android15-6.6.
- All of the above match by **exact `uname -r`**; when unmatched, tapping "One-Tap Jailbreak" immediately reports that the model is unsupported.
- All entry points run in place directly from the app's native libraries (`nativeLibraryDir`); the child process's cwd/HOME/TMPDIR are all in the app filesDir, and no tools or files are deployed to `/data/local/tmp`; ksud also runs in place from the installed manager APK. SUSFS is supported on the 6.18/6.12 branches (6.12 uses `libsusfs_guard_lkm_612.so`) and not on 6.6.118; the VFS switch is exposed only for the 6.18 entry point.
- For system research on your own devices only.
